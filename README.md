# 🛒 Shopping List App

A simple and elegant **ReactJS** application that helps users jot down their shopping list — including the product name, quantity, and unit (like ml, kg, piece, etc.).

## 🚀 Features

- ✅ Add items with **product name, quantity, and unit**
- 🧠 Data stored in **localStorage** (no backend required)
- 📱 **Mobile-first** responsive design
- 📦 **Progressive Web App** (PWA) support – install it like a native app!
- 🔐 **Form validation** for robust and error-free entries
- ⚡ Smooth animations and real-time feedback

## 🛠 Tech Stack

- **ReactJS**
- **Tailwind CSS**

### 📦 Additional Packages

- [`react-hook-form`](https://react-hook-form.com/) — for handling form inputs and validation
- [`framer-motion`](https://www.framer.com/motion/) — for sleek animations
- [`react-hot-toast`](https://react-hot-toast.com/) — for clean, customizable toast notifications

## 📱 Optimized For

- **Mobile screens** – quick access on the go
- **PWA capability** – install and use offline like a native app
